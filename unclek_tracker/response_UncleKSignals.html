    Stock Request Tool

    This feature provides members of Stock Waves, Metals, Mining & Agriculture, Crypto Waves, and World Markets the opportunity to request analysis on a symbol. Please click on the service name to see rules and guidelines for that service.

    To request a symbol:

    1. Make sure the desired service is selected from the pulldown if available.
    2. Type the symbol in the provided search box and hit enter.
    3. The system will pull matches that include a chart. If there hasn't been a recent update, click the link "Request an update for <symbol> -- X request(s) left" located just above the top post on the results page.
    4. You'll receive a pop-up notice confirming the request was submitted and also when the request has been filled.
